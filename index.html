1. Main (მთავარი)

გამარჯობა! მე ვარ გიორგი ბეჟიაშვილი 👋

Full-Stack დეველოპერი, რომელიც ორიენტირებულია მასშტაბური REST API-ებისა და სერვერული სისტემების შექმნაზე Nest.js, Node.js, TypeScript და MongoDB ტექნოლოგიების გამოყენებით.

🚀 გამორჩეული პროექტები

  • Social-Ts – სოციალური ქსელის REST API (JWT refresh rotation, Google OAuth, რეალურ დროში შეტყობინებები)

    ტექნოლოგიები: Node.js · TypeScript · MongoDB · Socket.io

  • Full E-Commerce Backend – მრავალგამყიდველიანი ელ-კომერციის API (Stripe Connect გადახდები და ClamAV ვირუსების სკანირება)

    ტექნოლოგიები: Node.js · TypeScript · MongoDB · Stripe

  • Newton – სრული სტეკის ფიზიკის შესასწავლი პლატფორმა

    ტექნოლოგიები: Node.js · TypeScript · Next.js · MongoDB

  • Auth Boilerplate – სამუშაოდ მზა ავტორიზაციის სტარტერი (JWT rotation, Google OAuth, timing-safe token შედარება)

    ტექნოლოგიები: Node.js · TypeScript · Passport
